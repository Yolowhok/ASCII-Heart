# ASCII Heart

Анимированные ASCII-виджеты для рабочего стола.

## Скачать для Windows

[**Скачать установщик Windows x64 (.exe)**](https://github.com/Yolowhok/ASCII-Heart/releases/latest/download/ASCII-Heart-1.6.0-Windows-x64-Setup.exe)

[Все релизы и контрольные суммы](https://github.com/Yolowhok/ASCII-Heart/releases)

Скачайте EXE и запустите его на Windows 10/11 x64. Node.js, Python и инструменты разработки для установки не нужны.

Внутри 12 сцен: шесть анимаций сердца, рождественская ёлка и пять дополнительных сцен, включая три версии Ember Warden, Emberblade и Heroine. Сцены включены в установщик.

Версия 1.6.0 собрана на macOS для Windows x64. Сборка, 14 автоматических тестов, целостность NSIS-установщика и состав библиотеки проверены. Запуск на Windows пока не проверен. Установщик не подписан цифровым сертификатом.
